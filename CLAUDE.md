# Project rules

## Cartoon shorts
- Every finished video gets a download button. Add it to the "Cartoon Shorts Shelf" page
  (https://claude.ai/artifact/LRkxDjKC1B2R1CHmr5vtUp, source: shorts/shorts_shelf.html): a card with a thumbnail,
  title, length, size and a "Download MP4" link to the file's GitHub raw URL
  (https://github.com/keithraphaelkeiji-123/BiyaheTa-Bai/raw/<branch>/<path>), newest first. Republish the page to the
  same URL (read it first from another session), then also send the MP4 with SendUserFile (display: attach).
- Commit each finished MP4 to the working branch so the raw link works.
